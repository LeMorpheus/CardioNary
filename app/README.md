# app — clinical dashboard

Built by both teams once the models, fusion and adaptation are complete. A
`dashboard` branch is created from `develop` at that point.

Requirements agreed so far:

- Multi-language interface.
- Suited to use as an edge tool: runs locally, with no cloud service in the loop.
- No red anywhere in the design.
- Reads results through `core.contracts`, so it works with both models unchanged.
