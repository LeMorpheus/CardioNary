# app — clinical dashboard

Built by both teams once the models, fusion and adaptation are complete. The lane
`app/dev` is cut from `develop` at that point.

Requirements agreed so far:

- Multi-language interface.
- Suited to use as an edge tool: runs locally, with no cloud service in the loop.
- No red anywhere in the design.
- Reads results through the interface in `core.contracts`, so it works with both models
  unchanged.
